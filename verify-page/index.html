Verify a proof

Check that a file matches a proof bundle and that its fingerprint was anchored on Solana. The file is hashed in your browser and never uploaded; only the anchor transaction is read from a public RPC endpoint.

A verified proof shows that a record existed unchanged at the stated time. It is not a priority right, does not replace a patent application, is not a token of ownership, and is not legal advice. The time is the network's block time (accurate to a few seconds).

A proof only counts if its anchor transaction was signed by an address you trust.
